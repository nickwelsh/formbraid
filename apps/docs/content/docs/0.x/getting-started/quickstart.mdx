This walkthrough assumes a Laravel application with React and the [local packages installed](./installation.mdx). Inertia is optional; Fetch is the default submission generator.

## 1. Scaffold frontend components

```sh
php artisan formbraid:init --register-vite
```

By default, init creates these user-owned files in `resources/js/formbraid`:

- `index.ts`: component-only React configuration exporting `Form` and `useForm`.
- `fields.tsx`: editable field controls using `useFieldContext`.
- `form-components.tsx`: editable form controls using `useFormContext`.
- `laravel.ts`: build-safe integration descriptor; it imports no UI modules.

Files are placed in `dirname(config('formbraid.metadata'))` if you change the metadata path. Rerunning init preserves existing files and edits. It does not create placeholder `_metadata.json`.

The component configuration has this shape:

```ts title="resources/js/formbraid/index.ts"
import { defineConfig } from '@formbraid/react';
import { TextField, NumberField, CheckboxField, DateField, SelectField, FileField } from './fields';
import { SubmitButton } from './form-components';

export const { Form, useForm } = defineConfig({
    components: { TextField, NumberField, CheckboxField, DateField, SelectField, FileField },
    formComponents: { SubmitButton },
    submitComponent: 'SubmitButton',
});
```

Keep literal component keys and statically inspectable objects. Use optional `groups` for composite controls. Do not register submissions or build integrations here.

## 2. Register the Vite integration

`--register-vite` edits only a standard literal `defineConfig({ plugins: [...] })`. For a complex config it prints manual instructions instead of rewriting application code. Add the imports and plugin alongside existing plugins:

```ts title="vite.config.ts"
import { defineConfig } from 'vite';
import { vitePlugin as formbraid } from '@formbraid/core/vite';
import laravelForms from './resources/js/formbraid/laravel';

export default defineConfig({
    plugins: [formbraid({ integrations: [laravelForms] })],
});
```

The scaffolded descriptor points to `./index.ts`, `./_metadata.json`, and `['php', 'artisan', 'formbraid:generate']`. Its PHP watch patterns cover requests, app code, routes, and config; generated outputs are excluded.

## 3. Write a request and controller

```php title="app/Http/Requests/UpdateProfileRequest.php"
<?php

namespace App\Http\Requests;

use Illuminate\Foundation\Http\FormRequest;

final class UpdateProfileRequest extends FormRequest
{
    public function authorize(): bool
    {
        return $this->user() !== null;
    }

    public function rules(): array
    {
        return [
            'name' => ['required', 'string', 'max:255'],
            'email' => ['required', 'email'],
        ];
    }
}
```

```php title="app/Http/Controllers/ProfileController.php"
<?php

namespace App\Http\Controllers;

use App\Http\Requests\UpdateProfileRequest;
use Illuminate\Http\JsonResponse;

final class ProfileController extends Controller
{
    public function update(UpdateProfileRequest $request): JsonResponse
    {
        $request->user()->update($request->validated());

        return response()->json(['saved' => true]);
    }
}
```

```php title="routes/web.php"
use App\Http\Controllers\ProfileController;
use Illuminate\Support\Facades\Route;

Route::patch('/profile', [ProfileController::class, 'update'])->middleware('auth');
```

The application must authenticate and authorize the operation. Generation reads metadata without running request authorization or validation. For the Inertia submission generator, use the application's normal Inertia response/redirect lifecycle instead of this Fetch-oriented JSON response.

## 4. Review config and start Vite

Defaults include `metadata = resources/js/formbraid/_metadata.json`, `output = resources/js/formbraid/laravel`, `component_enum = app/Formbraid/FormField.php`, and `submission_driver = Formbraid\Laravel\Drivers\Fetch::class`. Keep initial field mappings as strings such as `'string' => 'TextField'`; this lets the first metadata pass bootstrap without a generated enum.

Start the application's usual Vite dev command. Vite statically inspects TypeScript without evaluating component modules, atomically writes metadata, then runs Artisan. Artisan consumes JSON only. If `php artisan formbraid:generate` reports missing metadata, start Vite once rather than writing JSON by hand.

The PHP command emits one merged string-backed `App\Formbraid\FormField` enum for fields, form components, and groups. After this pass, generated cases can be used in request `fields()` / `groups()` and config mappings. Namespaces follow Composer PSR-4 mappings.

## 5. Render the descriptor

```tsx title="resources/js/pages/profile.tsx"
import { Form } from '../formbraid';
import { update } from '../formbraid/laravel/controllers/App/Http/Controllers/ProfileController';

export function Profile({ user }: { user: { name: string; email: string } }) {
    return <Form form={update} defaultValues={{ name: user.name, email: user.email }} />;
}
```

For this route without parameters, `update` is the exported callback-backed descriptor. For parameterized routes, the export is a factory: call `update({ user: 42 })` to obtain the descriptor directly. Neither has a `.form()` helper. Request definitions live under `requests/App/Http/Requests/UpdateProfileRequest.ts`, preserving namespaces.

Without children, the form renders fields and the configured submit component. Submission validates the draft, runs the generated callback, and maps server validation errors. Fetch handles same-origin credentials, the live URL-decoded XSRF cookie, multipart/method spoofing, and cancellation. For an existing Inertia React app, choose `Formbraid\Laravel\Drivers\Inertia::class`; generated code imports its router without a Formbraid adapter or manual CSRF setup.

Generated files are hash-owned; edits and unowned collisions are refused rather than overwritten. Customize scaffold files, not generated outputs. Continue with [layouts](../react/forms.mdx), [groups](../react/groups.mdx), [validation](../validation.mdx), and [generation](../laravel/generation.mdx).

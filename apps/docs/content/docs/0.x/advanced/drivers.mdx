---
title: Author a producer integration
description: Connect static component metadata to a backend generator without runtime drivers.
---

Producers emit core definitions and callback-backed descriptors. They do not register runtime submission drivers, parse executable JSON descriptors, or depend on an application-specific React configuration at runtime.

## Build-only contracts

`@formbraid/core/vite` exports `Integration`, `ComponentMetadata`, `RegistryManifest`, the static `inspectComponents(module, root)` inspector, and `vitePlugin({ integrations })`. `@formbraid/generator` is an optional producer-author SDK re-exporting that surface. Applications can use core's Vite entry directly; there is no generator CLI or frontend-framework generator pipeline.

```ts title="resources/js/formbraid/laravel.ts"
import type { Integration } from '@formbraid/core/vite';

export default {
    name: 'laravel',
    registry: new URL('./index.ts', import.meta.url),
    metadata: new URL('./_metadata.json', import.meta.url),
    command: ['php', 'artisan', 'formbraid:generate'],
    watch: ['app/**/*.php', 'routes/**/*.php', 'config/formbraid.php'],
    outputs: ['resources/js/formbraid/laravel/**', 'app/Formbraid/FormField.php'],
} satisfies Integration;
```

Register descriptors exclusively in Vite with `vitePlugin({ integrations: [laravelForms] })`. The descriptor is build-safe and must not import UI components. Registry and metadata URLs resolve relative to the descriptor; command execution and watch/output paths use the Vite root.

Vite is the sole metadata producer. It inspects TypeScript types without evaluating CSS imports or browser globals; writes the versioned metadata atomically; then invokes the backend command. Metadata includes fields, form components, groups, prop/slot shapes, and inspection inputs. Dev watching follows component imports and configured PHP patterns, including newly added app module directories. Changes coalesce; output exclusions prevent generation loops.

The backend consumes the finished JSON snapshot. It must not run frontend modules or invent metadata when the file is absent. For Laravel, a missing snapshot tells the user to start Vite once. Lower-level `formbraid:export` / `formbraid:http` commands remain useful for PHP inspection but do not replace this metadata boundary.

## Runtime output

Emit `defineForm` definitions that preserve literal field/component keys. Emit descriptors as `{ version: 1, definition, submission: { submit } }` (with optional `defaultValues`). The callback receives `(values, { signal, onProgress })` and returns an explicit result or `PromiseLike` result. Do not invent named JSON bindings or a separate editable draft store. Applications can override submission locally or use typed Effect operations.

## Laravel submission generators

The Composer package's PHP `Formbraid\Laravel\Contracts\SubmissionDriver` is a code-generation contract, not a runtime JavaScript driver:

```php
public function generate(string $endpoint, string $method): string;
```

`$endpoint` is a safe TypeScript expression, not a raw URL to quote again or an instruction to evaluate arbitrary code. Return a callback expression that explicitly maps success, invalid input, expected transport failures, and cancellation. Honor the signal and release resources. Use trusted producer-owned code for emission.

`Fetch` emits self-contained browser code with same-origin credentials, live URL-decoded XSRF cookie forwarding, multipart/method spoofing, and error/cancellation handling. `Inertia` emits a dynamic import of the existing app's `@inertiajs/react` router. Neither requires a Formbraid transport package or runtime registry.

Laravel outputs are hash-owned. Generation refuses edited or unowned files and manages obsolete owned outputs; scaffolds created by init remain user-owned and rerunnable without losing edits.

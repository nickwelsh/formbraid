---
title: Portable form descriptors
description: Produce callback-backed forms from any integration without a runtime registry.
---

Any package can produce forms for Formbraid. Generation is optional: React consumes core's framework-agnostic contract, not a Laravel or generator runtime. External integrations need only type imports to describe their form.

```ts
import type { FormDefinition, FormDescriptor, SubmissionCallback } from '@formbraid/core';

type TodoValues = { title: string; done: boolean };
declare const definition: FormDefinition<TodoValues>;

const submit: SubmissionCallback<TodoValues> = async (values, { signal }) => {
    // Application/integration code: wait for authoritative acceptance.
    const result = await prepareAndSubmit(values, signal);
    if (result.errors) return { status: 'invalid', errors: result.errors };
    return { status: 'success' };
};

const todoForm = {
    version: 1,
    definition,
    defaultValues: { title: 'Buy milk', done: false },
    submission: { submit },
} satisfies FormDescriptor<TodoValues>;
```

`prepareAndSubmit` represents the producer's own mutation implementation. The descriptor always carries `submission: { submit }`; there are no named driver bindings or runtime submission registry. Callbacks receive validated output and `{ signal, onProgress }`, returning an explicit `SubmissionResult` directly or through `PromiseLike`. Results are `success`, `invalid` (field/root errors), `failure` (expected error), `cancelled`, or `defect`. Use `SubmissionCallback<Output, Success, Error>` for typed payloads. Exceptions and rejected promises become defects; return expected failures explicitly.

## One session, one editable draft

An external hook can return `{ form: todoForm }` without importing the application's component configuration or creating a session:

```tsx
const { form } = useMutation(todo.update()); // External integration.
return <Form form={form} />;

// Or obtain programmatic access in a component:
const instance = useForm(form);
return <Form form={instance} />;
```

`Form` creates the session. Components read values, errors, and execution state from that session; a producer must not synchronize a separate editable-value store with it.

Definition defaults are the fallback, descriptor defaults override them, and explicit `defaultValues` override descriptor defaults. Defaults initialize a mount rather than resetting edits on rerender. Use a key or reset to switch records. React commits callbacks for future submissions; an active submission keeps its captured callback and values.

Local `submit` callbacks and Effect `operation` / `run` options remain available to replace descriptor execution. Bare definitions and initialized form instances remain supported. See [callbacks](../submission/callbacks.mdx) and [Effect operations](./headless.mdx).

## Cancellation and authority

Cancellation aborts the callback signal and suppresses late progress/outcomes. The integration owns underlying abort handling and cleanup. A durably queued or accepted server mutation may still execute; do not report success for an optimistic local write that can still be rejected.

## Metadata is not executable JSON

There is no executable JSON descriptor parser, `FormDescriptorData`, `FormDescriptorSchema`, or `bindForm`. JSON-only producers can supply metadata, but trusted producer/application code must validate it and attach a real callback before constructing a descriptor. Never evaluate callback source from untrusted JSON.

Core's extraction and JSON-value parsers remain useful at metadata boundaries; they do not construct submission callbacks. Native Effect schemas remain an optional definition extension for decoding and transformations. Preserve literal keys with `satisfies` or `defineForm<Values>()`, and declare editable default types explicitly so an empty draft does not narrow the entire value to a string literal.
